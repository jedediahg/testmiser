# Tests

`cli.sh` contains POSIX-shell integration checks for the wrapper, including exit propagation and a short-lived descendant. With ptrace permission it also checks network and mutation rejection. Unit checks cover SHA-256, Ed25519 attestation vectors/tamper rejection, command identity, v2 verification fingerprints, and bounded JSON/JCS behavior (duplicate keys, safe integers, Unicode, and canonical ordering). Run all checks with `make test`; OpenSSL EVP development files are required. When ptrace is unavailable, the CLI suite checks the uncached fallback. Add signed-record validation and trust-policy cases as those modules land.
