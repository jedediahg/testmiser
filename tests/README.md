# Tests

`cli.sh` contains POSIX-shell integration checks for the wrapper, including exit propagation and a short-lived descendant. With ptrace permission it also checks network and mutation rejection. Unit checks cover SHA-256, Ed25519 vectors/tamper rejection, command and verification fingerprints, bounded JSON/JCS behavior, and signed output-free records (golden ID, signature validation, policy scope, and canonical encoding). Run all checks with `make test`; OpenSSL EVP development files are required. When ptrace is unavailable, the CLI suite checks the uncached fallback. Extend result tests when policy-file loading and output manifests are implemented.
